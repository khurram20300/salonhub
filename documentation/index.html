2. Quick Start

Follow these steps to run the application locally on your machine:

Prerequisites

  • Node.js (v18.0.0 or higher recommended)
  • npm or yarn package manager

Installation

# 1. Extract the downloaded zip file & navigate to directory
cd salonhub

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev

# 4. Open in browser
http://localhost:3000

Building for Production

# Create optimized production build
npm run build

# Preview production build locally
npm run preview

4. Customizing Theme & Fonts

All core theme tokens, fonts, and glassmorphism utilities are defined in src/index.css.

Primary Gold Color Accent

To change the primary gold brand color, replace the hex values in src/index.css and Tailwind class usages:

/* Main Gold Accent */
#7b5900 -> Your Primary Color

/* Light Gold Highlight */
#c89b3c -> Your Secondary Color

Typography

The app imports Playfair Display for headings and Poppins for body text via Google Fonts in index.html.

5. Updating Data & Images

All salon listings, barber profiles, services, client bookings, and feed posts are stored cleanly in src/data/mockData.ts.

Simply update or replace the objects in mockSalons, mockBarbers, or mockBookings to personalize the content for your client.

6. Connecting Real Backend API

SalonHub uses standard TypeScript state management in src/App.tsx. To connect a REST API, GraphQL, Supabase, or Firebase backend:

  • Replace imports from ./data/mockData with useEffect fetch calls or React Query / Axios calls.
  • Use the TypeScript interfaces defined in src/types.ts to ensure exact data structure compliance.
